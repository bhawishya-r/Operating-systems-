# Operating Systems

A practical and conceptual journey through **Operating Systems**, focusing on understanding how operating systems work internally rather than simply memorizing definitions.

This repository contains my notes, experiments, commands, and practical labs as I learn Operating Systems from fundamentals to advanced concepts.

---

## 🎯 Goals

The goal of this repository is to:

- Understand how an Operating System works internally
- Learn how the OS manages hardware and software resources
- Understand the relationship between applications, the OS, and hardware
- Learn process and memory management
- Understand filesystems and storage
- Understand system calls and how programs interact with the kernel
- Learn Linux administration and troubleshooting
- Build practical labs to reinforce theoretical concepts
- Develop a strong foundation for Linux, cybersecurity, digital forensics, and system administration

---

## 🧠 Learning Philosophy

I don't want to learn Operating Systems by memorizing definitions.

For every important concept, I want to understand:

> **What is it?**  
> **Why s it exisdoet?**  
> **How does it work?**  
> **What happens internally?**  
> **How does the OS implement it?**  
> **How can I observe or demonstrate it practically?**

Whenever possible, theoretical concepts will be followed by experiments or labs.

Theory
   ↓
Understanding
   ↓
